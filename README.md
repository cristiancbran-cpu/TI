# Organigrama Savia Salud EPS - Vercel Deployment

Este proyecto es una página web diseñada para ser desplegada en Vercel a través de GitHub. 

La idea principal de este proyecto es mostrar todas las actividades que tiene el área de **Coordinación de Analítica y Ciencia del Dato**, donde cada jefatura y dirección tiene diferentes actividades.

## Ejemplo de Interactividad
Dentro del organigrama, las diferentes dependencias son interactivas. Como ejemplo demostrativo:
Al hacer clic sobre la **Jefatura Cuentas Médicas**, saltará una ventana emergente (modal) con la siguiente información:
- **Tiene 92 informes de Store procedure**
- **Tiene 1 tablero de BI llamado Productividad_Cuentas_Medicas**

Esta información fue extraída y contabilizada directamente del inventario oficial de tableros y bases de datos de la organización (hojas de BI y SP).
